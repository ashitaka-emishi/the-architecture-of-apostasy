# Liturgy Development Notes

The recovered full liturgy is preserved at `source/liturgy/The Liturgy of the Troth.md`.

## Structural logic

The liturgy works best as:

**gathering → naming → confession → repentance → hearing Scripture → examination → peace/reconciliation → intercession → common acclamation → commitment → sending**

“The Troth remains” changes pastoral function across the movement:
- opening: confession of prior order;
- confession: judgment;
- repentance: hope;
- reconciliation: ground of restoration;
- sending: commission.

## Current revision needs

2. Test every use of “keeper” so it does not imply a superior class.
