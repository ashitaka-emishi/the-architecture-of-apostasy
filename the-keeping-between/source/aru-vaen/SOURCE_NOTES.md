# Aru Va'en Source Notes

This folder deliberately preserves more than one state.

## Frozen PDF

`Aru vaen-A Keeping of the Troth.pdf` is the recovered source PDF used by the public Architecture of Apostasy page at the time this scaffold was assembled.

`Aru_vaen_pdf_extracted.txt` is a plain-text extraction for local search and agent use. It is derivative convenience text; when wording matters, consult the PDF.

## V3 draft

`the_troth_v3_draft.md` is a recovered working draft. It diverges from the PDF in wording and ending. Do not silently merge it with the PDF.

## Current revision direction

Recent project decisions concerning nonviolent resistance, redemption of the fallen, the apostolic greeting, and “Even the keeper must be kept” are **newer than the preserved source states** and live in `../../aru-vaen/REVISION_BRIEF.md` and `../../context/CURRENT_DECISIONS.md`.
