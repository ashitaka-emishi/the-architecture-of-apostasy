# Agent Prompt Tests

These lightweight tests describe expected behavior for every canonical agent.
They are prompt-discipline checks, not theological endorsements of simulated
outputs.

## Biblical Agent

- Test input: a draft claim that Exodus 32 proves all institutional symbolism is idolatrous.
- Expected behavior: identify Exodus 32 precisely, distinguish text from inference, flag proof-texting, surface rival readings, and ask for additional biblical controls.

## Historical Theology Agent

- Test input: a claim that all post-Constantinian church structures are apostate by definition.
- Expected behavior: ask for primary sources, distinguish historical description from theological synthesis, name likely objections, and avoid anachronism.

## Philosophy Agent

- Test input: a chapter paragraph that uses logos, symbol, causality, and embodiment interchangeably.
- Expected behavior: clarify distinctions, identify category errors, preserve theological priority, and mark unresolved conceptual risks.

## Psychology Agent

- Test input: a Chemical Temple paragraph that explains addiction as spiritual bondage without clinical qualification.
- Expected behavior: flag medical overreach, separate pastoral interpretation from diagnosis, identify missing sources, and recommend cautious language.

## Anthropology Agent

- Test input: a cultural-practice description that treats a whole community as captive to one ritual logic.
- Expected behavior: identify concrete practices, distinguish description from judgment, surface rival anthropological readings, and flag caricature risk.

## Systems Mapping Agent

- Test input: `architecture-of-apostasy/aspects/political-theology-and-war/war-as-fallen-liturgy.md`.
- Expected behavior: map created good, governing power, fall, Disordered Logos, fallen liturgies, Chemical Temple formation, sacrificial system, Christological restoration, and missing links.

## Diagram Agent

- Test input: a concept map connecting false logos, desire, practice, deformation, and sacrifice.
- Expected behavior: define nodes and directionality, use canonical labels, include accessibility notes, and state diagram limits.

## Image Review Agent

- Test input: `gallery/cracked-idol-with-red-void.jpg` plus the Visual Theology gallery canon.
- Expected behavior: classify image type, name source-note status, connect canonical terms, flag spectacle/despair risk, and require Christological resolution before canonical use.

## Critique Agent

- Test input: a public essay draft with strong historical and pastoral claims but thin citations.
- Expected behavior: lead with concrete risks, identify missing evidence, surface rival readings, and order revisions by severity.

## Editorial Agent

- Test input: a theologically intense essay section with mixed claim types and abrupt transitions.
- Expected behavior: clarify structure, normalize canonical terms, preserve voice, mark unsupported claims, and refuse to invent citations.

## Canonical Integration Agent

- Test input: an agent output proposing a new canonical term outside the existing ontology.
- Expected behavior: check constitutional fit, require review before acceptance, identify cross-reference impact, and decide accept, revise, hold, or reject.
