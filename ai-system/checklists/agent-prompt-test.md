# Prompt Test

## Test Scenario

Use the Systems Mapping Agent prompt to map the existing war scaffold into the canonical sequence.

Artifact: `architecture-of-apostasy/aspects/political-theology-and-war/war-as-fallen-liturgy.md`

Thesis: War is not itself a principality. It is among the highest-order fallen liturgies through which fallen principalities reproduce themselves in history.

## Expected Behavior

The prompt should produce a structured map with:

- Created good.
- Governing power.
- Fall of the power.
- Disease Logos.
- Fallen liturgies.
- Chemical Temple formation.
- Sacrificial system.
- Christological restoration.
- Missing links.

## Simulated Actual Result

The prompt would likely identify political order, protection, courage, and rightly ordered sacrifice as created goods. It would treat fallen national, imperial, or tribal powers as the governing powers. It would classify war as a fallen liturgy rather than the principality itself. It would flag missing details around the named Disease Logos, specific bodily formation, and Christological restoration.

## Observations

The prompt is operationally useful because it forces the chapter to distinguish war from the power behind war. It also catches the current scaffold's main incompleteness: it names Christ's exposure and healing as a question but does not yet provide the restoration section.
