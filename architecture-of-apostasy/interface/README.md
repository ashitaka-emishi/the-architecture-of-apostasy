# Interface

This folder defines how the Architecture of Apostasy and The Keeping Between speak to one another inside the larger project.

The interface exists to preserve equal weight without collapsing genres. The Architecture of Apostasy remains the analytic and diagnostic grammar of deformation. The Keeping Between remains the mythic, liturgical, doctrinal, and embodied discipline of faithful response under Christ.

Nothing in this folder promotes a Keeping Between proposal to public doctrine or canonical site content. Public promotion still happens through root Quarto pages, `markdown/`, and the repository's review process.
