# Architecture And Keeping

Status: Interface orientation

## Governing Relation

The Architecture of Apostasy diagnoses how created goods, agencies, authorities, institutions, identities, and symbolic orders become curved toward false ultimacy.

The Keeping Between develops the embodied disciplines by which fidelity is guarded under Christ amid that deformation.

The two bodies of work should be treated as equal-weight companions within the greater project:

| Architecture of Apostasy | The Keeping Between |
|---|---|
| Diagnostic grammar | Embodied discipline |
| Apostasy | Troth under Christ |
| False ultimacy | Christ as measure |
| Fallen powers | Guarded thresholds |
| Disordered Logos | Faithful witness and discernment |
| Fallen liturgy | Liturgy of return |
| Sacrificial victimization | Least-harm resistance |
| Institutional self-justification | Unclaimed Virtue |
| Beastification | Keeping without possession |
| Judgment of false continuity | Repentance and return |

## Non-Collapse Rules

The Keeping Between is not a mere application appendix to the Architecture of Apostasy.

The Architecture of Apostasy is not required to adopt Troth language as its technical vocabulary.

Keeping Between mythic terms must not be used as one-to-one equivalents for Architecture of Apostasy concepts unless a future approved interface document explicitly establishes that relation.

The Troth must not become a second Logos, deity, or autonomous principle alongside Christ. Christ remains the measure of both projects.
