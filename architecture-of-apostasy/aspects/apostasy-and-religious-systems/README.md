# Apostasy and Religious Systems

Develops the project's core critique of corrupted worship, institutional religion,
externalized holiness, law as self-justification, and holy symbols becoming idols.

Initial questions:

1. How does a divine gift become Nehushtan?
2. What patterns repeat across Israel and Church history?
3. How do religious institutions use grace as material for self-justification?
4. How does pruning function as mercy?
