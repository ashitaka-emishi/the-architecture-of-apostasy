# Fallen Liturgies

Develops the project's account of embodied rituals, habits, technologies,
institutions, and cultural practices that incarnate a Disordered Logos.

Initial topics:

1. War.
2. Politics.
3. Consumerism.
4. Entertainment.
5. Education.
6. Technology.
7. Money and Mammon.
