# The Chemical Temple

Develops the embodied theology of attention, desire, memory, trauma, addiction,
habit, emotion, imagination, and worship.

Initial questions:

1. How do liturgies form the body?
2. How can theology speak about neurochemistry without reductionism?
3. How should the project care for the long afflicted?
4. How does the Spirit reform desire and embodied worship?
