# Visual Theology

Develops the project's theology of images, diagrams, symbolic art, visual
metaphors, and gallery curation.

The actual public image files remain in `../../../gallery/` so the Quarto site can
publish them normally. Source notes and prompt/OCR text remain in
`../../../raw/images/`. This aspect governs how those images are interpreted,
classified, validated, and connected to the Grammar of Apostasy.

## Current Canon

- [Gallery Canon](gallery-canon.md)

## Initial Questions

1. What theological role does each image serve?
2. Is an image symbolic art, conceptual diagram, devotional image, warning image, or chapter illustration?
3. Which canonical terms does the image clarify?
4. What risks of ambiguity, sensationalism, or theological overstatement should be flagged?
5. How does the image resolve toward Christ rather than merely intensify darkness?
