# The Grammar of Apostasy: Agent Contracts

These contracts define the research and editorial roles used to develop chapters,
case studies, and diagrams within the shared grammar.

## Biblical Agent
Output:
- Relevant passages
- Exegesis
- Cross references

## Patristic/Theology Agent
Output:
- Augustine
- Aquinas
- Luther
- Calvin
- Bonhoeffer
- Girard
- Contemporary dialogue

## Psychology Agent
Output:
- Neurobiology
- Ritual
- Trauma
- Formation

## Systems Agent
Map findings into ontology:
Good Creation → Principality → Fall → Disease Logos → Liturgy → Chemical Temple → Sacrifice → Restoration

## Critique Agent
- Identify weak claims
- Competing interpretations
- Historical objections
- Scriptural tensions

## Diagram Agent
Generate printable conceptual diagrams.

## Editorial Agent
Normalize terminology and update glossary.
