# The Grammar of Apostasy

This folder is the internal grammar for the larger Architecture of Apostasy archive.
It keeps the shared vocabulary, ontology, chapter pattern, and analysis questions aligned
as essays and case studies are developed from different angles.

Use this material as the project canon for terms and structure, not as a finished public
essay. The public-facing works can vary in voice, but they should remain legible inside
this grammar.

## Core Ontology

God
→ Logos
→ Creation
→ Principalities (created to govern)
→ Fall of the Powers
→ Disordered Logos (false symbolic order)
→ Fallen Liturgies (embodied rituals)
→ Formation of the Chemical Temple
→ Individuals / Institutions / Civilizations
→ Christ
→ Restoration

## Universal Analysis Questions

1. What created good is being examined?
2. Which principality governs this domain?
3. How has that principality fallen?
4. What Disordered Logos is proclaimed?
5. What liturgies embody it?
6. How is the Chemical Temple formed?
7. What sacrificial system emerges?
8. How does Christ restore it?
