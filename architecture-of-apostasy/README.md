# The Architecture of Apostasy

This folder is the canonical theological workspace for the repository. It gathers
the constitution, grammar, conceptual roadmaps, and future theological subprojects
that govern the public archive.

The Quarto site still lives at the repository root so publishing remains stable.
This folder is where the deeper project architecture is developed before material
is promoted into public reading paths, essays, diagrams, or volumes.

## Structure

- `grammar-of-apostasy/` contains the canonical constitution, ontology, method, glossary, and editorial rules.
- `aspects/` contains brief scaffolds for major sub-aspects that should be developed under the main project.
- `interface/` contains cross-project orientation documents that describe how the Architecture of Apostasy and The Keeping Between relate without collapsing their genres.

The imported Keeping Between workbench lives at `../the-keeping-between/` as a sibling
workspace, not as a subfolder of this project.

AI-facing implementation material lives separately in `../ai-system/`.

Public gallery image assets remain in `../gallery/`, with the theological canon for
image use developed under `aspects/visual-theology/`.
